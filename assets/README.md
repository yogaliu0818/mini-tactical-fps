# Weapon assets

`karambit.obj`, `m16.obj`, and `pistol.obj` come from the [Low Poly Weapon Pack](https://opengameart.org/content/low-poly-weapon-pack) by byzmod3d.

`arms.glb` comes from [WRAD ARMS](https://github.com/wwwriks/wrad-arms) by wwwriks.

`rifle_real.glb` is the runtime-normalized version of `m16.obj`. Its missing source MTL was
replaced with a neutral matte gunmetal material so the model remains usable in the browser.

The game uses the authored high-tech view models `rifle.glb`, `pistol.glb`, and `karambit.glb`.
