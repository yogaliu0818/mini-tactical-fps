# 戰術前線 — 迷你 FPS

一款原創的單檔瀏覽器戰術射擊遊戲原型，使用 Three.js 與 WebGL。遊戲採用原創練習場、模型和玩法，不使用其他遊戲的素材。

## 遊玩

直接開啟 [GitHub Pages 網頁](https://yogaliu0818.github.io/mini-tactical-fps/)（啟用 Pages 後），或在本機透過簡單 HTTP 伺服器提供 `index.html`。遊戲需要網路連線載入 Three.js CDN。

## 操作

- `WASD`：移動
- 滑鼠：瞄準
- 滑鼠左鍵：射擊
- `R`：裝填
- `Shift`：衝刺
- `1` / `2`：切換步槍／手槍
- `B`：暫停
- `Esc`：解除滑鼠鎖定並暫停

## 內容

- 多回合敵人遭遇戰與掩體
- 可見射擊曳光線、命中火花與爆頭傷害
- 步槍、手槍、裝填與移動／連射散佈
- 回合間商店：購買護甲、彈藥與武器傷害升級
- 分數、金錢、生命與護甲 HUD

## GitHub Pages

在儲存庫設定中開啟 **Settings → Pages**，將部署來源設為 `Deploy from a branch`、分支選 `main`、資料夾選 `/(root)`。部署完成後，網站網址為：

https://yogaliu0818.github.io/mini-tactical-fps/
